# Changelog

## v1.0.0 – First release

- Every entry is a folder; click a folder to see its code in full screen
- Full screen has Copy all code, text size buttons and a Details button
- Add a question, screenshots and code; the date and time are saved automatically
- One-click Copy code on every folder and on every entry page
- Search by title, question, tag or code, and filter by language
- Works offline and installs on Android and Windows
- Trash with Restore, unsaved-draft recovery, and Export / Import backup
- Optional cloud sync with Supabase (sign in under Settings)
